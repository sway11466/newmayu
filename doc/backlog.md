## index

次回採番: bug=3 / feature=20 / refactoring=1.

項目（バグ bug / 機能追加 feature / リファクタリング refactoring）を追加するときは、該当カテゴリの採番を +1 して ID を継ぐ。完了した項目は本書から削除し、番号は再利用しない（過去の使用済み番号は `git log -p -- doc/backlog.md | grep -oE '(bug|feature|refactoring)-[0-9]+' | sort -u` で確認できる）。状態は「本書に載っていれば未完了／消えていれば完了」で表す（状態列は持たない）。ゴールは、その作業で何が達成されていれば終わりなのかを1文で書く。手段ではなく到達点を書く。

考慮外は、外したい軸があるときだけ足す。「この作業では○○は考えない」と書く。書いていなければ制限は無い。

### feature-15

**ブラウザの入力欄での &Recenter**
- ゴール：ブラウザの複数行の入力欄でも、C-L でキャレット行が画面の中央に来る。
- 背景：yamy の `&Recenter` はクラス名が `Edit` / `RichEdit…` の複数行の窓にしか効かない。ブラウザの入力欄はブラウザが自分で描いているので、`EM_LINESCROLL` などのメッセージが届かない。yamy に無い挙動になる。
- 対応：候補は (1) UI Automation の `ScrollIntoView`（寄せられるのは上端か下端だけ）、(2) newmayu と一緒に配るブラウザ拡張（JavaScript で中央寄せ。ブラウザごとに作る）。未決：やるかどうか、どちらで実現するか。
- 該当：未定。

## 実機で未確認

実装とテストは済んでいるが、実機で動かして見ていないもの。見て問題なければ本書から消す。

- トレイメニューの「再読込」：押すとログに「再読込: パス」が出て、`.mayu` の変更が効く。
- &Recenter：emacsedit.mayu の C-L で、複数行の Edit / RichEdit のキャレット行が縦の中央に来る。それ以外の窓では何も起きない。
- 起動できないときのメッセージボックス：`yamy.ini` の選択中の設定に存在しない `.mayu` のパスを書いて起こすと、ログと同じ理由がメッセージボックスにも出る。
- 設定の一覧：yamy の `yamy.ini` を newmayu.exe と同じフォルダに置くと、選択中の設定が読まれる。トレイの「選択」に一覧が並び、選ぶとその設定に切り替わる。「設定」でダイアログが出て、追加・編集・削除・並べ替え・参照ができ、OK で `yamy.ini` に書かれて読み直される。`yamy.ini` も `.mayu` も無いと、起動時に設定ダイアログが出る。
- 案内の窓（&HelpMessage / &HelpVariable）：出たとき、ピンを押したときに、フォーカス窓からフォーカスを奪わない。
- &WindowIdentify / &LoadSetting：コンソールで default.mayu の C-S-D を押しても、CLASS・TITLE・位置と大きさがログに出る。`&LoadSetting("名前")` でその名前の設定に切り替わり、一覧に無い名前ならログに `unknown setting name` が出る。
- &DescribeBindings：Word で C-S-/ を押すと、ログに Word のキーマップから Global までの割付が yamy と同じ形で並ぶ。
- ログダイアログ：トレイの「ログ」で出て、起動時の見出しと設定の読み込みのログが並ぶ。「詳細」を付けるとキー変換・フォーカスの行も出る。「ログのクリア」で消えて見出しが出直す。「フォントの変更」でログの文字がすぐ変わり、`yamy.ini` の `logFont` に書かれる。「閉じる」で隠れる。default.mayu などの `&MayuDialog(Log, …)` / `&LogClear` も同じく効く。再読込に失敗するとログダイアログが出る。
