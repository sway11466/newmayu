# バックログ

未完了の作業（バグ・機能追加・リファクタリング）を追跡する統合リスト。

## index

次回採番: bug=1 / feature=4 / refactoring=1.

項目（バグ bug / 機能追加 feature / リファクタリング refactoring）を追加するときは、該当カテゴリの採番を +1 して ID を継ぐ。完了した項目は本書から削除し、番号は再利用しない（過去の使用済み番号は `git log -p -- doc/backlog.md | grep -oE '(bug|feature|refactoring)-[0-9]+' | sort -u` で確認できる）。状態は「本書に載っていれば未完了／消えていれば完了」で表す（状態列は持たない）。ゴールは、その作業で何が達成されていれば終わりなのかを1文で書く。手段ではなく到達点を書く。

考慮外は、外したい軸があるときだけ足す。「この作業では○○は考えない」と書く。書いていなければ制限は無い。

## 機能追加

実装済みコードに足す機能。採番は本書冒頭「index」。各エントリは 背景／ゴール／対応／該当 で記す。

### feature-1

**`.mayu` の文字コード自動判定（CP932 対応）**
- ゴール：yamy 時代の CP932 で書かれた `.mayu` を、変換せずそのまま読み込める。
- 背景：`.mayu` の読み込みは BOM 無し UTF-8 のみとし、それ以外は読み込みエラーにしている。yamy の配布ファイルと yamy 時代の設定は CP932。コメントだけでなくキー名（`半角/全角`・`無変換` など）にも日本語が入るため、文字コードを誤ると照合に失敗して読み込めない。
- 対応：バイト列から UTF-8 か CP932 かを判定して復号する。完全な判定は無理なので、判定できないときはエラーにして文字コードを伝える。
- 該当：`src/config/`（ファイルの読み込み口）。

### feature-2

**複数スキャンコードのキー（Pause）**
- ゴール：`def key Pause = E1-0x1d 0x45` のように複数スキャンコードで定義したキーが、yamy と同じく押下 1 回として割付に使える。
- 背景：yamy の `Key` はスキャンコードを最大 4 個持ち、エンジンは届いたコードを順に貯めて、定義の先頭部分に一致するうちは次を待ち、完全一致で 1 キーとして処理する（`searchKey` / `searchPrefixKey`）。配布ファイルで使うのは Pause の 1 件。パーサーの最小サブセットでは、スキャンコードが 2 個以上の `def key` は読み込みエラーにしている。
- 対応：(1) `model::Key` を複数スキャンコード対応にする。(2) エンジンに「コードを貯めて定義と照合する」処理を足す。(3) WH_KEYBOARD_LL で Pause がどう届くか（E1-0x1d と 0x45 が順に来るか、0x45 単体か）を実機で測り、フック側の変換を合わせる。(4) パーサーのエラーを外す。
- 該当：`src/model.rs`・`src/engine.rs`・`src/platform.rs`・`src/config/`。

### feature-3

**実機テストの自動化（テスト入力モード）**
- ゴール：人がキーを押さずに、フック → エンジン → SendInput の通しが「A を押すと B が出る」の形で確認できる。
- 背景：エンジンとパーサーは `cargo test` で自動化済み。フックから先は実機で手で押して確かめている。ソフトウェアから流した入力（`SendInput`、SendKeys、スクリーンキーボード）には OS が「注入された」印（`LLKHF_INJECTED`）を付け、フックは自分の出力を拾わないためにその印の付いた入力を素通しする。そのためテストの入力も素通しされる。印が付かない入力はドライバ層（仮想キーボードドライバ・USB マイコン）からしか作れず、テストのためには重い。
- 対応：(1) テスト用の入力に `dwExtraInfo` で印を付け、その印がある注入入力だけ物理入力として扱う起動モードを newmayu に足す。(2) テスト用プロセスが入力を注入し、別の WH_KEYBOARD_LL フックで newmayu の出力を記録して期待値と比べる。(3) デスクトップセッションが要るので CI では動かさず、手元で実行するテストとして置く。
- 該当：`src/main.rs`・`src/platform.rs`（印の判定）・テスト用の実行ファイル（新規）。
